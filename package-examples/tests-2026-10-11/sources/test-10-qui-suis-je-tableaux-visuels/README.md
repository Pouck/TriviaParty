# TEST Qui suis-je ? — Tableaux révélés

Import this package to try all four visual reveal styles. It contains six image-only questions with six 16-second effect stages plus a seventh 16-second stage showing the original image: pixelation, blur, tile shuffle, and tile uncovering. The answer appears only after the host reveals it.

The image files are included locally for offline play. See `IMAGE-CREDITS.md` for attribution.
