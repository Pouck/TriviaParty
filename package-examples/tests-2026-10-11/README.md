# Forfaits de test — une question par forfait

Sélectionnez plusieurs forfaits pour enchaîner les écrans. Les mises de catégorie peuvent être proposées sur tous ces forfaits.

L’ancien format « ordering » est automatiquement converti en QCM par l’application actuelle : il ne réactive pas les curseurs. Le forfait « Mise — ancien format » teste le format de question conservé ; pour tester les mises actuelles, utilisez le bouton de mise au début de la catégorie.

Carte — repères utilise la carte schématique de secours ; Carte — image utilise une vraie illustration existante.
